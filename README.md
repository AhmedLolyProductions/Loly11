# Loly11
This iso image was made by doing the following steps:<br>

**1.** Install the tiny11.iso onto a computer<br>
**2.** Set it up using [my tutorial](https://github.com/AhmedLolyProductions/Windows-Setup-Manual)<br>
**3.** Add some customization in my taste (eg. wallpaper)<br>
**4.** Capture the Current state of the Hard Drive and convert it to an iso image (via [Hiren's bootCD](https://www.hirensbootcd.org))<br>
